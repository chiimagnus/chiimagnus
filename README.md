I build native Apple apps, developer tools, and experiments in AI, spatial computing, and games.

## Currently building

- **[Bailey](https://github.com/chiimagnus/Bailey)**: A native, customizable AI IDE for macOS, with terminals, code editing, Git, and a browser in one workspace.
- **[SyncNos](https://github.com/chiimagnus/SyncNos)**: A local-first web clipper for AI chats, articles, and video transcripts, with browser extensions and CLI automation.
- **[HappyPianist](https://github.com/chiimagnus/HappyPianist)**: Spatial piano practice on Apple Vision Pro, with MusicXML guidance and audio, MIDI, and virtual piano input.
- **[Roamer](https://github.com/chiimagnus/Roamer)**: CLI automation for the Apple Vision Pro Simulator, including spatial input, app inspection, and recording.
- **[AppleBooksCLI](https://github.com/chiimagnus/AppleBooksCLI)**: A native macOS CLI for Apple Books, covering your library, annotations, exports, and safe edits.
- **[Richman3D](https://github.com/chiimagnus/Richman3D)**: A 3D board game for desktop browsers, with single-player and multiplayer modes.
- **[TreeHerder](https://github.com/chiimagnus/TreeHerder)**: An early-stage plugin marketplace for Bailey.
- **[AppleMapsCLI](https://github.com/chiimagnus/AppleMapsCLI)**: My fork of an Apple Maps CLI, adding ordered multi-stop routes.

## Earlier projects and experiments

- **[logseq-AIsearch](https://github.com/chiimagnus/logseq-AIsearch)**: Context-aware AI search and summarization for Logseq notes.
- **[Salu](https://github.com/chiimagnus/salu)**: A turn-based card game in Swift, with a CLI and an experimental visionOS version.
- **[VibeSports](https://github.com/chiimagnus/VibeSports)**: A camera-controlled running and boxing game prototype for macOS.
- **[LihuaCat](https://github.com/chiimagnus/LihuaCat)**: A local CLI that turns photos into short story videos.
- **[FrameWeavers](https://github.com/chiimagnus/FrameWeavers)**: Front-end work on a team project that turns videos into illustrated stories with AI.
- **[Vniverse](https://github.com/chiimagnus/Vniverse)**: A macOS reader for PDFs, Markdown, and AI chats, with text-to-speech.
- **[StreamVoice](https://github.com/chiimagnus/StreamVoice)**: A SwiftUI client for GPT-SoVITS streaming speech synthesis on macOS.
